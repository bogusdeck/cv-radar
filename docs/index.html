⚡ SYSTEM FEATURES

🎯
ATS SCORING ENGINE
Go-powered scoring engine evaluating exact keyword matching, keyword density, role fit, and penalty checks for major ATS platforms.
🔍
MISSING KEYWORD AUDIT
Scans Job Descriptions and pinpoints every required skill, tool, and qualification missing from your resume.
🖥️
TERMINAL UI DASHBOARD
Interactive cv-tui dashboard built with Go & Bubble Tea for live platform scoring, grade calculation (A–F), and missing keyword lists.
🤖
UNIVERSAL AI SKILL
Auto-discovered skill for Antigravity (agy), Claude Code (claude), Codex, and OpenCode. Just say /cv-optimizer.
⚡
HEADLESS AI REWRITER
Background execution script (optimize.sh) that orchestrates LLMs to rewrite your CV without manual copy-pasting.
📄
TECTONIC PDF TYPESETTING
Compiles optimized LaTeX code directly into clean, production-grade PDF resumes ready for submission.

SUPPORTED AI CODING CLIs

agy (Antigravity) claude (Claude Code) codex (Codex) opencode (OpenCode) cv-tui (Standalone CLI)

👾 ATS PLATFORM STRATEGIES

PLATFORM SCORING STRATEGY KEY FOCUS
WORKDAY Strict exact-keyword matching Requires precise terminology from the JD. Heavy penalties for missing skills.
TALEO Keyword density scoring Boosts scores when critical JD keywords are repeated across summary and experience points.
GREENHOUSE Semantic AI + human reviewer fit Focuses on natural phrasing, contextual impact, and measurable achievements.
iCIMS Mixed exact + semantic match Primary weight on job title alignment, structural cleanliness, and date formats.
